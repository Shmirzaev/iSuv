# iSuv

Government-grade regional water operations, accounting, monitoring, and decision-support platform.

## Creative landing MVP

The approval-stage prototype is in [`landing-mvp/`](landing-mvp/).

```bash
cd landing-mvp
npm test
npm run dev
```

The prototype uses clearly labeled synthetic data and does not connect to or control real water infrastructure. Review the direction in `docs/design/LANDING_MVP_REVIEW.md` before starting production landing work or the full platform task graph.
